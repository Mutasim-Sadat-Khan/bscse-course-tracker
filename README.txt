INSTALLABLE ECE COURSE TRACKER — GITHUB PAGES

Upload ALL of these files to the root of your existing public GitHub repository:
  index.html
  manifest.webmanifest
  sw.js
  icons/icon-192.png
  icons/icon-512.png
  icons/apple-touch-icon.png

Keep the icons folder name and directory structure exactly as provided.
You can upload all files together by dragging the EXTRACTED contents into the GitHub Upload files area.
Do not upload only index.html; browser installability needs the manifest and icon files.

Existing Firebase Authentication and Firestore settings need no changes.
Your current progress is in browser storage and Google cloud (if signed in), not in this zip.

Install on PC/Android: click Install app or use your browser's install icon/menu.
Install on iPhone: use Share -> Add to Home Screen (browsers do not permit automatic iOS installs).

Installing may use a separate app storage profile: sign in with Google to sync your existing saved records.
